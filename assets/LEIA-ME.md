# Carro personalizado

Coloque aqui um modelo 3D chamado `carro.glb` (formato glTF binário) e recarregue o jogo:
ele substitui o coupé desenhado no código. O modelo é centralizado e escalado para ~4,45 m automaticamente.

Se o carro aparecer de ré ou de lado, crie `carro.json` nesta pasta:

```json
{ "rotacaoGraus": 180 }
```

As rodas do modelo ficam paradas (não giram nem esterçam). Confira a licença do modelo antes de usar.
